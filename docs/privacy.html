Privacy Policy

Last updated 20 September 2026

The short version

Tempra collects nothing about you. It has no accounts, no analytics, no crash reporting, and no servers. Nothing you do in the app is transmitted anywhere. The only network request Tempra ever makes is to GitHub, to ask whether a newer version has been released, and you can turn that off.

What the app stores, and where

Tempra keeps its settings on your Mac and nowhere else, in the standard macOS preferences location for the app and in its application support folder. This includes:

  • the rules you create, and which apps they apply to;
  • your profiles and preferences, such as appearance and monitoring settings;
  • a local history of CPU measurements and rule activity, kept for up to twenty-four hours and seven days respectively so the graphs and activity list have something to show.

All of it stays on your machine. Deleting Tempra and its preferences removes it. None of it is uploaded, backed up by us, or shared with anyone, because there is no "us" on the other end of a connection.

What the app reads while it runs

To do its job, Tempra reads information about processes running on your Mac: their names, process identifiers, CPU usage, memory usage, whether they are playing audio, and whether their windows are visible. Lowering the priority of processes owned by other users additionally requires an administrator helper, which Tempra asks permission to install.

This information is read in memory, shown to you, and used to decide when a rule applies. It is never written to a remote service. The diagnostic export feature writes a file only when you explicitly ask for one, and only to the location you choose; you decide whether to send it anywhere.

Network activity

Tempra contains no networking code of its own. It bundles the Sparkle update framework, which checks a release feed hosted on GitHub to see whether a newer version exists. That request goes to GitHub, not to us, and is subject to GitHub's own privacy practices. It carries no identifier we created. You can disable update checks in the app's settings, after which Tempra makes no network requests at all.

If you download Tempra from GitHub or visit this website, GitHub receives the request as it would for any page it serves. We do not run analytics on this site and set no cookies.

Children

Tempra is a general-purpose utility, is not directed at children, and collects no personal information from anyone, including children.

Third parties

There are no third-party analytics, advertising, or tracking components in Tempra. The only third-party code in the app is the Sparkle update framework and an SMC temperature reader adapted from an open-source library, both credited in the repository.

Your rights

Privacy regulations give you rights to access, correct, export or delete personal data a service holds about you. Tempra holds none, so there is nothing to request. Your local settings are yours, in plain files on your own disk, and you can inspect or delete them at any time.

Verifying any of this

You do not have to take this document's word for it. Tempra is licensed under the GPL-3.0 and the complete source is at github.com/AxxzyWasTaken/Tempra. Searching the source for networking code is a reasonable way to spend five minutes before trusting a process-control utility, and it is encouraged.

Changes

If this policy ever changes, the updated version will be published on this page with a new date, and the change will be visible in the repository's history.

Contact

The fastest route is a GitHub issue. Security matters should follow SECURITY.md and be reported privately rather than in a public issue.
